# QS Robot Hub · 机器人管理平台 α 版原型

模舆（SpaceMoR）机器人管理平台 α 版高保真交互原型。单文件静态站点，无构建依赖，任意静态服务器 / 直接双击 `index.html` 即可运行。

## 目录结构

```
qs-robot-proto/
├── index.html          # 当前最新版本（线上链接指向它）
├── versions/           # 历史版本存档（每轮修改一个快照）
│   └── v2.html
├── proto_shots/        # 页面素材（Logo / 3D 视口 / 导航地图 / 机器人照片）
├── README.md
└── CHANGELOG.md        # 版本变更记录
```

## 版本规则（每次修改生成一个版本）

1. 每轮修改确认后：版本号 +1（v2 → v3 → v4 …），在 `CHANGELOG.md` 记录改动点；
2. 旧版本快照复制到 `versions/v{N}.html`，`index.html` 始终是最新版；
3. git 提交并打标签 `v{N}`，可随时回滚、可对比任意两版差异；
4. 线上地址始终访问最新版，历史版可通过 `versions/v{N}.html` 路径访问。

## 信息架构口径（V2，2026-08-18 确认）

- **泛化层（4 菜单固定）**：监控中心 / 任务中心 / 空间管理 / 接入中心
- **场景层（场景包，可配置）**：人防巡检 / 工地质安 / 园区巡检 ≤3 平铺，>3 收敛为「场景工作台」；纯业务算法、工单以插件形式接入
- **系统层（弱入口 ⚙）**：菜单与场景配置 / 权限 / 网络策略默认值 / 对接管理 / 主键冻结

详见工作区《α版信息架构设计原则.md》（12 条确认口径）。
